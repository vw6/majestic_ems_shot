# majestic ems shot

**Скриншотер-биндер для EMS (Majestic RP).** Живёт в трее, ловит горячую клавишу,
делает снимок текущего монитора и **сам раскладывает его по папкам** в зависимости
от режима: **ПМП / Смены / Прогулы**.

Нативное Windows-приложение (C# / WinForms / .NET 8), один самодостаточный `.exe` —
ставить ничего не нужно.

> Автор: **.foodoch** · по всем вопросам — Discord: `.foodoch`

## Установка

1. Скачай `MajesticEmsShot.exe` из [релизов](../../releases) (один файл, ~69 МБ, .NET внутри).
2. Запусти — в трее появится значок.
3. При первом запуске Windows SmartScreen может ругнуться (файл без цифровой подписи):
   **«Подробнее» → «Выполнить в любом случае»**.

Клавиши по умолчанию:

| Клавиша     | Действие                    |
|-------------|-----------------------------|
| `F12`       | Снимок в текущем режиме     |
| `Ctrl+F12`  | Следующий режим             |
| `Alt+F12`   | Начать / завершить смену    |

- **Левый клик** по значку в трее — открыть настройки.
- **Правый клик** — меню (режимы, папка, сжатие снимков, выход).
- Клавиши переназначаются в настройках кнопкой «забиндить» (жмёшь — приложение слушает нажатие). Поддерживается нумпад отдельными кодами.

## Куда падают снимки

```
<База>/<неделя>/<день>/<режим>/…
```

Например:

```
D:\скрины\
└── 20-26 июля 2026\
    └── воскресенье 26\
        ├── ПМП\        09-14-22.png …
        ├── Смены\       10-01-05.png …
        └── Прогулы\
            ├── 1\  … до 8 фото
            ├── 2\  … до 8 фото
            └── …
```

База по умолчанию — `Изображения\MajesticEmsShot`, меняется в настройках.

## Режимы

### Прогулы
Снимок всегда уходит в **самую пустую незаполненную** папку (при равенстве — в младшую
по номеру). Когда партия заполнена (по умолчанию 10 папок × 8 фото = 80), создаётся новая.
Счётчик всегда отражает **реальные файлы на диске**: «сделано», «полных папок»,
«до заполнения» (= цель − сделано). Можно вручную удалять/добавлять файлы — подстроится.

### ПМП
Каждый снимок = один ПМП. Баллы зависят от **времени снимка**:
- дневной (по умолчанию 07:00–22:00) — `1` балл;
- ночной — `2` балла.

Баллы копятся **по всем папкам «ПМП»**, пока файлы не удалены (не сбрасывается по неделям).
Есть опция **«сокращённый день в выходные»** — по субботам и воскресеньям ночь начинается
на час раньше. Статус: дневных / ночных / баллов / до следующего повышения.

### Смены
Отсчёт идёт от **последнего снимка** в режиме «Смены»; норма = длительность смены
(по умолчанию `30` мин). Оверлей показывает «прошло» и «осталось», а цвет статуса:
- **серый** — снимков ещё нет;
- **зелёный** — время есть;
- **красный** — пора приготовиться (за N минут до нормы);
- **красный + мигание** — за 10 секунд до нормы и когда время вышло.

> Все пороги (минуты, баллы, часы дня/ночи, число папок) настраиваются.

## Оверлей поверх игры

Компактная HUD-плашка со статусом (режим + счётчики) в стиле лаунчера Majestic:
тёмная скруглённая панель, акцентная полоса, жирный заголовок, крупные значения.

- Тянется мышью, **позиция запоминается**.
- Держится поверх всех окон, не забирает фокус у игры.
- Работает поверх **оконного / безрамочного** режима (полноэкранный эксклюзив оверлеи
  не пропускает — переключи игру в borderless).

## Звук снимка

При снимке играет звук затвора (свой `.mp3`, встроен в exe). При спаме снимков предыдущий
звук обрывается и играет новый — без «хвоста» очереди. Громкость регулируется в настройках,
звук можно выключить.

---

## Размер снимков (для Discord)

Discord режет крупные вложения, поэтому:
- новые снимки сохраняются сразу **не больше 9 МБ** (лимит в настройках; при превышении
  разрешение автоматически уменьшается, формат остаётся PNG);
- уже накопленные скрины можно ужать разом: правый клик по трею → **«Сжать большие снимки»**.

## Настройки и данные

- Конфиг: `%APPDATA%\MajesticEmsShot\config.json`
- Состояние смен: `%APPDATA%\MajesticEmsShot\state.json`
- Звук снимка: `%APPDATA%\MajesticEmsShot\shutter.mp3` (извлекается из exe)

Удалишь эти файлы — вернутся значения по умолчанию.

## Сборка из исходников

Нужен **.NET SDK 8+** (https://dotnet.microsoft.com/download/dotnet/8.0).

```bat
build.bat
```

или вручную:

```bat
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
```

Готовый `publish\MajesticEmsShot.exe` самодостаточен.
